# Combo Produtividade 10X — Landing Page Scaffold

A clean, responsive HTML–CSS–JS scaffold for the "Combo Produtividade 10X" landing page. Built mobile‑first, modular, and ready for deployment on GitHub Pages.

## Structure

```
.
├── index.html        # Semantic HTML5, sections scaffolded
├── style.css         # Reset, variables, utilities, responsiveness
├── script.js         # DOM bootstrapping + placeholders
└── assets
    ├── images/       # Hero, logos, testimonials
    ├── icons/        # Favicon and UI icons
    └── placeholder.txt
```

## Development

- Edit `index.html` sections: HERO, BENEFITS, OFFER, TESTIMONIALS, CTA, FOOTER.
- Add images/icons under `./assets/images` and `./assets/icons`.
- Keep paths relative (e.g., `./assets/images/hero.png`).

## GitHub Pages Deployment

1. Push to the default branch (e.g., `main`).
2. In GitHub: Settings → Pages → Build and deployment → Source: `Deploy from a branch`.
3. Branch: `main`, Folder: `/root`. Save.
4. Wait for Pages to build, then open the provided URL.

Notes:
- `index.html` must remain at the repository root.
- All asset links are relative and compatible with project pages.
