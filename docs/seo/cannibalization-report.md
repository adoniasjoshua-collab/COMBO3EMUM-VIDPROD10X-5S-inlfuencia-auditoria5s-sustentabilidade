# Relatório de canibalização

Atualizado em 2 de setembro de 2026.

| Intenção | Decisão | Motivo |
|---|---|---|
| gestão do tempo | Preservar `/produtividade/gestao-do-tempo/` e `/ferramentas/gestao-do-tempo/` | Uma página ensina; a outra executa como WebApplication |
| 5S e produtividade | Preservar `/produtividade/5s-e-produtividade/`; nova mineração é contextual | Intenções geral e setorial distintas |
| gestão ambiental na mineração | Publicar em `/mineracao/` e não duplicar em `/gestao-ambiental/` | Um único pilar setorial |
| segurança e riscos na mineração | Manter páginas separadas | Segurança aborda sistema de gestão; riscos aborda reconhecimento e controle |
| NR-22 Parauapebas | Não criar | A norma é nacional; página local linka o pilar |
| NR-22 Canaã dos Carajás | Não criar | Evita doorway local |
| cursos para mineração | Fortalecer `/carreira-mineracao/como-trabalhar-na-mineracao/` | A consulta integra a intenção de preparação profissional; não há evidência para outra URL |
| profissões na mineração | Fortalecer `/carreira-mineracao/como-trabalhar-na-mineracao/` | O guia agora diferencia famílias de funções sem prometer requisitos universais |
| técnico ambiental mineração | Cobrir no guia de carreira e no pilar ambiental | Uma página própria ainda teria risco de conteúdo curto e sobreposição |
| técnico de segurança mineração | Cobrir no guia de carreira e no pilar de segurança | Uma página própria exigiria escopo ocupacional e regulatório independente |
| resíduos na mineração | Fortalecer `/gestao-ambiental/gestao-de-residuos/` e ligar ao pilar mineral | A intenção geral e a aplicação setorial são atendidas sem criar uma página duplicada |
| cronômetro de tarefas e gestão do tempo | Preservar `/ferramentas/gestao-do-tempo/` como ferramenta | `/produtividade/gestao-do-tempo/` mantém a intenção educativa; links deixam clara a diferença |
| 5 sensos japoneses e o que é 5S | Concentrar em `/5s/o-que-e-5s/` | Variações da mesma intenção conceitual foram incorporadas à resposta existente |
| continuidade operacional na mineração | Concentrar em `/mineracao/produtividade-na-mineracao/` | O conceito é um componente da produtividade sistêmica e não justifica URL isolada agora |
| químicos na mineração | Não criar nesta onda | Conteúdo técnico precisa de fonte e escopo específicos |
| melhoria contínua mineração | Não criar nesta onda | Intenção atendida inicialmente por produtividade na mineração |
| gestão do tempo mineração | Não criar nesta onda | Conteúdo geral + produtividade setorial resolvem o percurso |
| páginas para outros municípios | Não criar | Sem evidência de intenção e conteúdo local suficiente |
| ferramentas Pomodoro/Eisenhower | Não publicar ainda | Existem artigos, mas as aplicações ainda não estão funcionais |

Nenhuma URL antiga foi consolidada, redirecionada ou removida.
