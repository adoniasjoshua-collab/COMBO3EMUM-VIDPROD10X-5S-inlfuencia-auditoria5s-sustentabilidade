# Arquitetura de links internos

## Regras

1. Todo artigo recebe link do hub, breadcrumbs, conteúdo relacionado e rodapé.
2. Âncoras descrevem a página de destino; evitar “clique aqui”.
3. Links contextuais conectam intenção, não apenas keywords.
4. Nenhum link aponta para URL de roadmap ainda inexistente.
5. A Home comercial continua levando ao portal e à ferramenta sem virar índice editorial.

## Fluxos prioritários

- NR-22 → segurança → riscos → 5S → produtividade → curso.
- Gestão ambiental na mineração → resíduos → educação ambiental → 5S.
- Canaã/Parauapebas → carreira → NR-22 → fontes oficiais.
- Carreira → como trabalhar → MEC/Sine → Tempo 10X.
- 5S mineração → fundamentos 5S → segurança → produtividade.
- Portal → hubs → artigos → ferramenta → conteúdo relacionado.

## Distribuição

O menu mantém os principais clusters. O rodapé adiciona Mineração, Carreira e Ferramentas. Páginas GEO apontam entre si apenas quando a comparação regional ajuda o leitor. Links comerciais aparecem após resposta educativa, em CTA identificado.
